# Mac mini 自动连接 JBL Flip 6

登录 Mac 后自动连接蓝牙音箱 JBL Flip 6，并设为默认声音输出。
找不到音箱、连不上或音箱没开机时，自动切回 Mac mini 自带扬声器。

安装后会得到一个可双击的应用「连接Flip6」，登录时系统会自动运行它，需要时你也可以手动双击它。

## 使用前提

1. 音箱已经在「系统设置 → 蓝牙」里**配对过一次**（脚本只连接已配对的设备，不负责首次配对）。
2. 电脑上装有 [Homebrew](https://brew.sh)（安装程序会用它装 `blueutil` 和 `switchaudio-osx`）。

## 安装

方式一（推荐）：在访达里**双击 `双击安装.command`**。
第一次打开如果提示“无法验证开发者”，请右键点它 → 选「打开」→ 再点「打开」。

方式二：打开「终端」，进入本文件夹后运行：

```bash
bash install.sh
```

装好后会立刻运行一次。第一次运行时 macOS 会弹出“「连接Flip6」想使用蓝牙”的提示，请点「允许」。

## 日常使用

- **开机后**：登录 Mac 时自动运行，不用做任何事。
  Mac mini 如果没有设置自动登录，会在你输入密码登录之后才运行。
- **手动连接**：音箱是登录之后才开机的，双击「应用程序」文件夹（用户目录下的 `~/Applications`）里的「连接Flip6」即可，
  也可以把它拖到程序坞（Dock）上，一键运行。
- **查看结果**：运行后会弹出系统通知；详细记录在

  ```bash
  cat ~/Library/Logs/flip6-autoconnect.log
  ```

## 工作流程

1. 蓝牙没开则先打开。
2. 在已配对设备里找名字含 `Flip 6` 的音箱。找不到则直接切回自带扬声器。
3. 找到后尝试连接，最多等 60 秒（音箱刚开机时给它时间）。
4. 连上后等系统出现该音箱的音频输出，把声音输出和系统提示音都切过去。
5. 超时、没出现音频输出等任何失败情况，都切回 Mac mini 自带扬声器，并弹出系统通知说明原因。

## 可调整的设置（可选）

新建文件 `~/.config/flip6-autoconnect.conf`，按需写入下面几行（不写则用默认值）：

```bash
DEVICE_NAME="Flip 6"        # 蓝牙名称里包含的关键字，不区分大小写
FALLBACK_OUTPUT=""          # 留空=自动找 Mac mini 自带扬声器；也可写死，如 "Mac mini扬声器"
CONNECT_TIMEOUT=60          # 最多等多少秒让蓝牙连上
NOTIFY=1                    # 1=弹出系统通知，0=不弹
```

## 常见问题

**没有弹出蓝牙权限提示，或者开机后没反应**
先看日志。然后到「系统设置 → 隐私与安全性 → 蓝牙」，确认列表里有「连接Flip6」并且开关是打开的。
没有的话，点「+」，选择 `~/Applications/连接Flip6.app`（访达里按 `Cmd+Shift+G` 输入 `~/Applications` 即可找到），再重新登录一次。

**提示“生成应用失败”**
说明没能生成可双击的图标，但安装程序已经改为登录时直接运行脚本，自动连接功能不受影响。
这种情况下蓝牙权限在「系统设置 → 隐私与安全性 → 蓝牙」里添加 `blueutil`（位置：`/opt/homebrew/bin` 或 `/usr/local/bin`）。

**音箱名字不是 Flip 6**
在配置文件里把 `DEVICE_NAME` 改成蓝牙列表里显示的名称里的一段关键字。

**自带扬声器没切成功**
运行 `SwitchAudioSource -a -t output` 查看设备的准确名字，填进配置里的 `FALLBACK_OUTPUT`。

## 想在“快捷指令”App 里也能用

打开「快捷指令」→ 新建 → 添加操作「运行 Shell 脚本」→ 内容填：

```bash
open ~/Applications/连接Flip6.app
```

这样就能用快捷指令、Siri 或菜单栏图标来触发连接。登录自动运行不依赖它，已经由安装程序设置好。

## 卸载

```bash
bash uninstall.sh
```
